# MTC 2.1.2 Plus — 0.1.2 통합 수정판 (BE 26.60)

[통합 MTC 다운로드](https://raw.githubusercontent.com/mchoe5699/mtc_addon_plus/main/downloads/v0.1.2/MTC_Addon_Plus_26.60.mcaddon)

기존 MTC 행동 팩 1개와 리소스 팩 1개 안에 철도 운영 기능을 통합한 개발판입니다. 별도 확장 팩은 없으며 기존 MTC 호환 차량 팩은 필요합니다. 원본 팩 UUID를 유지하고 버전은 `[2,1,205]`입니다.

이번 수정은 기존 MTC 엔티티 선로와 대시보드 선로의 연속 3차원 추종, 앞·뒤 대차의 경사·곡선 계산, 후속 차량 이동 방향을 다룹니다. 새 선로의 모델 앞 방향과 경사 표시를 수정하고, 곡선을 정확한 제어점으로 보존하며, 선로가 되접히는 잘못된 제어점은 거절합니다. 구형 차량 모델의 기울기 표현 범위도 7.875도에서 최대 45도로 확장했습니다.

기존 대시보드 선로는 로드된 열차의 추종 과정에서 경사 표시값을 갱신합니다. 예전 균등 곡선 점은 검증 후 연속 곡선으로 복원합니다. 이미 잘못 생성된 선로는 새 버전에서 다시 만드세요. 실제 BE 26.60 및 사용하는 차량 팩에서 경사·곡선 주행을 재시험해야 합니다.

자동 테스트 38개, 확장 코드 타입 검사, 통합 패키지·리소스 보존·경사 렌더 설정·재현 빌드 검사를 통과했습니다. 테스트는 게임 물리·렌더링 자체를 실행하지 않으므로 모든 차량 팩에서 해결되었다고 보장하지 않습니다.

대시보드·구획 지정·노선별 시간표·자동 왕복·수동 운전·레드스톤과 17종 레일 프로필을 포함합니다. 안내방송은 Minecraft 채팅 TTS를 이용하므로 청취자가 접근성 설정에서 채팅 텍스트 음성 변환을 켜야 합니다.
