# MTC Addon Plus 0.1.0 — BE 26.60 개발판

[애드온 다운로드](https://raw.githubusercontent.com/mchoe5699/mtc_addon_plus/main/downloads/v0.1.0/MTC_Addon_Plus_26.60.mcaddon)

MTC 2.1.2 기반 철도 확장팩입니다. 대시보드, 구획 선택, 노선별 시간표와 자동 왕복 운행, 수동 운전, 레드스톤 입력·점유 출력, 17종 레일 프로필을 포함합니다. 기존 MTC 호환 차량 팩이 별도로 필요합니다.

안내방송은 Minecraft의 채팅 TTS 기능을 이용합니다. 청취자는 설정 → 접근성에서 채팅 텍스트 음성 변환을 켜야 합니다. 직접 음성 합성이나 입체 음원 방송은 지원하지 않습니다.

자동 테스트 24개와 확장 코드 타입·패키지 검사를 통과했습니다. 실제 BE 26.60에서 팩 가져오기·차량 물리·한국어 낭독은 미검증이며 MTR 시스템의 완전한 이식은 아닙니다. 테스트 월드에서 사용하세요.

원본 MTC 저자: @mca_be_official (첨부 원본 매니페스트 표기). 사용자가 제공한 MTC 원본을 기반으로 빌드했습니다. 원본 저작권은 원저작자에게 있으며 MTR 코드·음원·모델은 포함하지 않았습니다.

파일 무결성은 SHA256SUMS로 확인할 수 있습니다.
