# MTC 2.1.2 Plus — 0.1.1 통합 개발판 (BE 26.60)

[통합 MTC 다운로드](https://raw.githubusercontent.com/mchoe5699/mtc_addon_plus/main/downloads/v0.1.1/MTC_Addon_Plus_26.60.mcaddon)

기존 MTC 행동 팩과 리소스 팩 안에 철도 대시보드, 구획 지정, 노선별 시간표·자동 왕복 운행, 수동 운전, 안내방송, 레드스톤과 17종 레일 프로필을 추가한 통합판입니다. 원본 MTC 행동 팩 1개와 리소스 팩 1개만 포함하며 별도 확장 팩을 적용하지 않습니다. 기존 MTC 호환 차량 팩은 필요합니다.

팩의 이름은 `MTC 2.1.2 Plus (26.60)`입니다. 원본 UUID를 유지하고 버전은 `[2,1,204]`입니다. 이전 버전의 `MTC+ Railway Controller`와 `MTC+ Railway Resources`를 적용했다면 월드를 백업하고 두 별도 확장 팩을 비활성화한 뒤 통합판을 적용하세요. 이전 별도 확장 팩의 노선 설정은 자동 이전되지 않으므로 다시 등록해야 합니다.

안내방송은 Minecraft의 채팅 TTS 기능을 이용합니다. 청취자는 설정 → 접근성에서 채팅 텍스트 음성 변환을 켜야 합니다. 직접 음성 합성이나 입체 음원 방송은 지원하지 않습니다.

자동 테스트 24개와 타입·통합 패키지 검사를 통과했습니다. 원본 파일·텍스처·번역 보존, 원본 스크립트 진입점에서 통합 기능 로드, 팩이 원본 MTC 두 개뿐인지 검사했습니다. 실제 BE 26.60에서 가져오기·차량 물리·한국어 낭독은 미검증이며 MTR의 완전한 이식은 아닙니다.

원본 MTC 저자: @mca_be_official (첨부 원본 매니페스트 표기). 원본 저작권은 원저작자에게 있으며 MTR 코드·음원·모델은 포함하지 않았습니다. 파일 무결성은 SHA256SUMS로 확인할 수 있습니다.
