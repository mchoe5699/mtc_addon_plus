# MTC 2.1.2 Plus — 0.1.3 통합 수정판 (BE 26.60)

[통합 MTC 다운로드](https://raw.githubusercontent.com/mchoe5699/mtc_addon_plus/main/downloads/v0.1.3/MTC_Addon_Plus_26.60.mcaddon)

기존 MTC 행동 팩 1개와 리소스 팩 1개 안에 기능을 추가한 통합판입니다. 원본 팩 UUID를 유지하고 버전은 `[2,1,206]`입니다. 기존 MTC 호환 차량 팩이 필요합니다.

선로의 장식 모델은 충돌이 없어 플레이어가 통과할 수 있었습니다. 새 선로에는 밟을 수 있는 자갈 받침 블록을 함께 생성합니다. 기존 선로 근처에서는 **대시보드 → 주변 선로 받침 생성**을 선택하세요. 주변 64블록에 로드된 기존 MTC 엔티티 선로와 새 대시보드 선로를 대상으로 공기에만 받침을 추가합니다. 기존 자갈·나무·건물은 덮어쓰지 않습니다. 받침은 1/16블록 단위의 충돌 상자를 사용하며, 선로 삭제 후에도 지형으로 남습니다.

열차는 받침의 단차가 아닌 연속 3차원 곡선을 따릅니다. 추종이 시작된 차량은 임시 이동 후 재보정하는 두 번의 위치 전송 대신 최종 선로 위치를 한 번 전송합니다. 후속 차량도 부모 차량의 후진 방향을 따릅니다. 기존 MTC 선로 추종, 대차 경사, 새 선로 모델 방향·경사 표시 수정도 포함합니다.

자동 테스트 43개와 타입·팩 구조·충돌 상자·모델·스크립트 문법·재현 빌드 검사를 통과했습니다. 실제 BE 클라이언트의 보간과 차량 팩 스크립트는 별도 확인이 필요하며, 실제 게임에서 끊김이 모두 해결되었다고 검증한 상태는 아닙니다. 월드를 백업하고 새 버전으로 업데이트한 뒤 시험하세요.

노선별 시간표·자동 왕복·수동 운전·레드스톤과 17종 레일 프로필을 포함합니다. 안내방송은 Minecraft 채팅 TTS를 사용하며 청취자의 접근성 설정에서 채팅 텍스트 음성 변환을 켜야 합니다.
