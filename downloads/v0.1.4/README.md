# MTC 2.1.2 Plus — 0.1.4 통합 수정판 (BE 26.60)

[통합 MTC 다운로드](https://raw.githubusercontent.com/mchoe5699/mtc_addon_plus/main/downloads/v0.1.4/MTC_Addon_Plus_26.60.mcaddon)

기존 MTC 행동 팩 1개와 리소스 팩 1개 안에 기능을 추가한 통합판입니다. 원본 UUID를 유지하며 팩 버전은 `[2,1,207]`, 표시 이름은 `MTC 2.1.2 Plus 0.1.4 (26.60)`입니다. 기존 MTC 호환 차량 팩은 필요합니다.

0.1.3에서 남아 있던 원본 MTC 후속 차량의 이중 위치 전송을 실제 패키지의 이동 콜백 실행 테스트로 재현하고 제거했습니다. 선로 추종 중에는 이전의 ‘차체 기울기 끄기’ 설정이 경사 적용을 막지 않게 하고, 정차 시 반복 위치 전송도 제거했습니다. 기존 선로 검색은 월드 전체 대신 주변 공간으로 제한해 부하를 줄였습니다.

업데이트 후 대시보드 상단에 **실행 버전 0.1.4**가 표시되는지 확인하세요. 열차 옆에서 **경사 추종 상태 확인**을 열면 추종 작동 여부, 목표 경사, 실제 차체 속성값과 오류를 확인할 수 있습니다. 문제가 계속되면 이 화면과 실제 움직임을 함께 확인해야 합니다.

선로를 통과하는 플레이어를 위한 받침 블록도 포함합니다. 기존 선로 근처에서 **주변 선로 받침 생성**을 실행하면 공기에만 밟을 수 있는 받침을 추가하며 기존 블록은 보존합니다. 새 대시보드 선로에는 받침이 함께 생성됩니다.

자동 테스트 50개와 타입·패키지 검사를 통과했습니다. 이 중 5개는 패키지에 들어간 실제 MTC 이동·기울기 함수를 모의 API에서 실행합니다. BE 게임 엔진이나 실제 클라이언트 렌더링은 검증하지 않았으므로 게임에서 확인이 필요합니다.

대시보드, 구획 지정, 노선별 시간표·자동 왕복·수동 운전, 레드스톤, 17종 레일 프로필을 포함합니다. 안내방송은 클라이언트의 채팅 TTS 기능을 사용합니다.

원본 MTC 저자: @mca_be_official (첨부 매니페스트 표기). 원본 저작권은 원저작자에게 있으며 MTR 코드·음원·모델은 포함하지 않았습니다. SHA256SUMS로 파일 무결성을 확인할 수 있습니다.
